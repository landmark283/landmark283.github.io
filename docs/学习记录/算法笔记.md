## 优化常用技巧和原理

### 局部性原理

- **空间局部性**：指一旦CPU访问了某个内存地址，那么**它附近相邻**的内存地址在接下来也很可能被访问。所以优化时要尽量让数据在内存中**连续存放**（比如用数组而不是链表），这样CPU的硬件预取机制才能提前把数据加载到缓存。

- **时间局部性（Temporal Locality）**：指一旦CPU访问了某个数据，**过一会儿**它很可能**再次**被访问。所以优化时要尽量把频繁使用的变量放进寄存器，或者把循环中重复用到的数据缓存起来。

因此我们要尽可能让数据在内存中连续存放，并且尽量让被频繁访问的数据处在固定的位置。比如下面这段代码：

```cpp
//高效版本 比下面快4ms
class Solution {
public:
    int maxProfit(vector<int>& prices, int fee) {
        int len=prices.size();
        int buy,sell=0,temp,p;
        buy=0-prices[0]-fee;
        for(int i=1;i<len;++i){
            temp=buy;
            p=prices[i];   //使用单独的数字来存放接下来会被访问的数据
                           //经过编译器优化，它们会存放在固定的寄存器中，编译出的汇编指令更简洁
                           //这里提升了3ms
            buy=max(buy,sell-p-fee);
            sell=max(sell,temp+p);
        }
        return sell; //去掉了没有意义的比较，提升了1ms
    }
};
//低效版本
class Solution {
public:
    int maxProfit(vector<int>& prices, int fee) {
        int len=prices.size();
        int buy,sell=0,temp;
        buy=0-prices[0]-fee;
        for(int i=1;i<len;++i){
            temp=buy;
            buy=max(buy,sell-prices[i]-fee);
            sell=max(sell,temp+prices[i]);
        }
        return max(buy,sell);
    }
};
```







### 使用哈希表优化重复计算

在很多递归算法当中，直接写很容易出现大量重复的计算。如果使用哈希表（条件允许的话用数组更快），存放这些数据，就可以避免重复计算。

例题：

小偷又发现了一个新的可行窃的地区。这个地区只有一个入口，我们称之为 `root` 。

除了 `root` 之外，每栋房子有且只有一个“父“房子与之相连。一番侦察之后，聪明的小偷意识到“这个地方的所有房屋的排列类似于一棵二叉树”。 如果 **两个直接相连的房子在同一天晚上被打劫** ，房屋将自动报警。

给定二叉树的 `root` 。返回 ***在不触动警报的情况下** ，小偷能够盗取的最高金额* 。

这个算法题的解决思路是基于动态规划的：

考虑每个房间有两种状态：偷和不偷，分别计算出两种状态时，小偷在该房间级其所有子房间所能偷到的最多钱。这样从下往上递归，每次都是增加一个父节点去计算新的最大值，下方的子节点不会受到影响，就可以确保算法计算出的结果是正确的。

具体写的时候，使用深度优先的递归策略，写出来的代码自然就是从下往上递归。以下代码超时。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int rob_dp(TreeNode* root,bool isval){
        if(root==nullptr) return 0;
        if(isval){
            return rob_dp(root->left,false)+rob_dp(root->right,false)+root->val;
        }
        else{
            return max(rob_dp(root->left,false),rob_dp(root->left,true))+max(rob_dp(root->right,false),rob_dp(root->right,true));
        }
    }
    int rob(TreeNode* root) {
        //由于这里两个输入一个是ture，一个是false，后续至少要重复算一次。实际上遍历
        //时候false和true取最大值也会导致重复计算
        return max(rob_dp(root,false),rob_dp(root,right));
    }
};(root,right));
    }
};
```

发现了重复计算之后，使用哈希表存放每个指针计算出来的结果，避免重复计算，大幅提升效率。以下代码通过（11ms）。

```cpp
class Solution {
public:
    unordered_map<TreeNode*,int> f,g;
    //f代表isval取true，也就是打劫root
    void rob_dp(TreeNode* root){
        if(root==nullptr) return;
        
        rob_dp(root->left);
        rob_dp(root->right);
        f[root]=g[root->left]+g[root->right]+root->val;
        g[root]=max(f[root->left],g[root->left])+max(f[root->right],g[root->right]);
    }
    int rob(TreeNode* root) {
        f[nullptr]=0;g[nullptr]=0;
        rob_dp(root);
        return max(f[root],g[root]);
    }
};
```

这里的哈希表起到的作用和常见的动态规划题目中使用的数组是一样的：存放计算的数据。并且甚至都可以被优化：所有子节点计算出的两个数值都只会被使用一次：用于计算出父节点的两个数值。那么我们就可以自己写一个数据结构来完成这部分的数值传递，从而减少空间的消耗。此外，不使用map，也可以极大的减小开销（map创建新键值对的开销是比较大的，通常我们在需要反复检索数据的情况下使用map，但是如刚才分析的一样，我们的所有数据都只会被使用一次，这种情况下用map就很蠢）。以下代码通过（0ms）。

```cpp
struct datastruct{
    int isvaled;
    int novaled;
};
class Solution {
public:
    //f代表isval取true，也就是打劫root
    struct datastruct rob_dp(TreeNode* root){
        if(root==nullptr) return{0,0};

        auto left = rob_dp(root->left);
        auto right = rob_dp(root->right);
        int isvaled = root->val+left.novaled+right.novaled;
        int novaled = max(left.novaled,left.isvaled)+max(right.novaled,right.isvaled);
        return {isvaled,novaled};
    }
    int rob(TreeNode* root) {
        struct datastruct r =rob_dp(root);
        return max(r.isvaled,r.novaled);
    }
};
```

为什么选择结构体来传递数据？因为结构体是一个对象，它的内存是分配在栈上的。一来不需要手动管理，二来分配和销毁的速度也很快。如果使用一个vector<int>来存放数据，效率会低很多。并且vector和map一样，并不适合在这样只负责传递值的场景下使用。



例题2

二叉树中的 **路径** 被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中 **至多出现一次** 。该路径 **至少包含一个** 节点，且不一定经过根节点。

**路径和** 是路径中各节点值的总和。

给你一个二叉树的根节点 `root` ，返回其 **最大路径和** 。![](C:\Users\moon%20side\AppData\Roaming\marktext\images\2026-07-15-11-25-15-image.png)

同样的动态规划思路：既然是一条路径，那么子节点就只能从左右子节点当中选一个，以此递归，递归的时候，我们只需要获取左右子节点的路径和即可。然后，因为不一定包括根节点，那么在每个子节点计算的时候，都把它当做是根节点计算一下数值，并且用这个数值来作为最大值。另外，路径是可以中断的，如果说某个子节点计算出来了，自己这条支路的路径和是负数，那么我们就把它置0，相当于不要它们了。

```cpp
class Solution {
public:
    int maxPathsub(TreeNode* root,int* maxi){
        if(root==nullptr) return 0;
        int l=maxPathsub(root->left,maxi);
        int r=maxPathsub(root->right,maxi);
        int temp=l+r+root->val;
        if(temp>*maxi) *maxi=temp;
        return max(0,max(l,r)+root->val);
    }
    int maxPathSum(TreeNode* root) {
        int answer=INT_MIN;
        maxPathsub(root,&answer);
        return answer;
    }
};
```
