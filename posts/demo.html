排版示例

2026-10-19 · 模板

这一页只是给我自己看的样板：把常用的元素摆一遍，写文章时照着改就行。看完可以删掉它，记得同时删掉 blog.html 和首页里的那两条链接。

二级标题

正文段落。行高 1.75，单行大约 62 个字符宽——这个宽度读起来不累。段落里可以有 加粗、斜体、链接，以及行内代码 git push。

列表

  • 无序列表的第一项，写短一点
  • 第二项，可以带 代码
  • 第三项
  1. 有序列表也一样
  2. 用来写步骤

引用

引用块用左侧一条细线标出来，颜色比正文浅。适合放别人说过的话，或者自己觉得值得单独拎出来的一句。

代码块

git add .
git commit -m "add a new post"
git push

好了，就这些。剩下的靠内容本身。
